- The brushed finish reuses a cached 4 × 4 texture tile instead of constructing a full-screen line path on redraw.
- Streaming source opening moves from MainActor into a cancellable user-initiated worker. File opening and audio-session configuration begin concurrently. File ownership transfers only after the worker finishes; audio-graph mutation stays on MainActor and still checks the preparation generation. `audio.streaming.ready elapsedMs=…` records source/session/graph readiness.
- Local preparation, including paused restoration, now counts as busy library work and cancels competing scans. Cancelled metadata scans stop scheduling new metadata requests and do not replace the complete metadata cache with partial results.

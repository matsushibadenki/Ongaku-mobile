# Ongaku 1.0.6

## 日本語

- Apple標準再生からアプリ内の高音質再生への切り替えを改善しました。
- 非DRM曲の再生準備とエフェクト適用の安定性を改善しました。
- Google Driveなどのリモート音源取得とキャッシュ処理を改善しました。
- 楽曲ごとに歌詞の表示タイミングを調整できるようになりました。
- 再生画面の表示、リピート・シャッフル操作の分かりやすさを改善しました。

## English

- Improved transitions from Apple system playback to in-app high-quality playback.
- Improved playback preparation and effect activation for non-DRM tracks.
- Improved remote audio downloads and cache handling, including Google Drive.
- Added per-track lyrics timing adjustments.
- Refined the player interface and repeat/shuffle controls.

## 简体中文

- 改善了从 Apple 系统播放切换至应用内高音质播放的体验。
- 提升了非 DRM 曲目的播放准备和音效启用稳定性。
- 改进了包括 Google Drive 在内的远程音频下载和缓存处理。
- 新增按曲目调整歌词显示时间的功能。
- 优化了播放界面及重复播放、随机播放控件。

## Distribution status

The GitHub release contains the source code. App Store availability is tracked separately in [the deployment record](DEPLOYMENT_READINESS_2026-10-16.md). DRM-protected tracks continue to use Apple system playback; app effects are available only on supported unprotected sources.
